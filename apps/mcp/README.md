# @agent-ledger/mcp

Open-source MCP bridge for Agent Ledger.

Tools:

- `audit_record` — send an audit event to the tenant-scoped hosted ledger.
- `audit_usage` — read metered tenant usage.
- `audit_verify_file` — verify a local JSONL chain without network access.

Set `AGENT_LEDGER_URL` and `AGENT_LEDGER_API_KEY` before starting the server.
