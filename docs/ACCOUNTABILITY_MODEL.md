# Accountability model
Agent Ledger is the system of record for consequential autonomous-agent actions. Observability explains execution; Agent Ledger adds durable attribution and verification.

Each action should answer: **who** (agent/version), **what** (action/tool/resource), **why** (trace/task), **authority** (principal), **policy** (policy/version/decision), **result**, and **evidence** (event hash, chain position, receipt).

A receipt is not a compliance certification. `VERIFIED` means the hosted event exists and the available integrity/attribution checks passed. Independent anchoring is only asserted when an external anchor is actually configured and verified.
